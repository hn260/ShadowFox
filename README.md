# ShadowFox AI Machine Learning Internship Projects

## Overview

This repository contains the projects completed during my Machine Learning Internship. The projects demonstrate the practical implementation of Machine Learning and Natural Language Processing techniques using Python and popular open-source libraries.

Each project follows a complete machine learning workflow including:

- Data Collection
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Selection
- Model Training
- Model Evaluation
- Performance Analysis
- Future Improvements

## Projects

### Task 1 – Boston House Price Prediction

Developed a regression model to predict housing prices using various housing attributes such as crime rate, number of rooms, tax rate, and other socioeconomic features.

---

### Task 2 – Car Price Prediction

Built a regression model capable of predicting used car selling prices based on multiple vehicle attributes including fuel type, ownership, transmission, age, and kilometers driven.

---

### Task 3 – AI-Driven Natural Language Processing

Implemented text generation using OpenAI's GPT-2 Language Model through Hugging Face Transformers and explored its capabilities using multiple prompts.
